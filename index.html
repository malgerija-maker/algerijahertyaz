1.Tanpa Generic

  • ​Generic adalah istilah yang digunakan untuk menyatakan sesuatu yang bersifat umum, tidak spesifik, dan dapat digunakan dalam berbagai situasi atau kebutuhan. Istilah ini sering digunakan dalam berbagai bidang, seperti bahasa, teknologi, obat-obatan, dan pemrograman. Dalam kehidupan sehari-hari, sesuatu yang generic berarti tidak memiliki ciri khusus atau hanya bersifat umum saja. Dalam dunia pemrograman, generic digunakan agar suatu kode dapat dipakai untuk berbagai tipe data tanpa harus membuat kode yang berbeda-beda. Dengan adanya generic, program menjadi lebih fleksibel, efisien, dan mudah digunakan kembali. Oleh karena itu, generic sangat membantu dalam membuat program yang lebih sederhana dan terstruktur.

  dynamic data;

  int value = box.data;

  box.data = "Hello";

  print("Data setelah diubah: ${box.data}");
}

3.Sintaks Generic Class dan Function

  • Method getData() digunakan untuk mengambil nilai yang tersimpan di dalam class sesuai dengan tipe data yang telah ditentukan.
  • Selain itu, terdapat generic function yaitu myFunc<T> yang dapat menerima dan mengembalikan nilai dengan tipe yang sama, sehingga fungsi ini juga bersifat fleksibel terhadap berbagai tipe data.

Kode Program VS Code:


// Nama  : M.ALGERIJA HERTYAZ PASLAM
// NIM   : 251410021
// Kelas : SI2A
class MyClass {
  T data;

  MyClass(this.data);

  T getData() {
    return data;
  }
}

// Generic function
T myFunc(T value) {
  return value;
}

void main() {
  var myInt = MyClass(10);
  var myString = MyClass("test");

  print(myInt.getData());
  print(myString.getData());

  var intValue = myFunc(100);
  var stringValue = myFunc("hello");

  print(intValue);
  print(stringValue);
}

4.kelas Box

  • Variabel _value bersifat private dan digunakan untuk menyimpan nilai, sedangkan getter value digunakan untuk mengambil nilai tersebut dari luar class.
  • Method setValue() digunakan untuk mengubah nilai yang ada di dalam objek Box sesuai dengan tipe data yang telah ditentukan.

  T? _value;

  Box(this._value);

  T? get value => _value;

  void setValue(T value) {
    _value = value;
  }
}

void main() {
  var intBox = Box(10);
  print("Int Box: ${intBox.value}");

  intBox.setValue(20);
  print("Set Int: ${intBox.value}");

  print("String Box: ${stringBox.value}");

  stringBox.setValue("World");
  print("Set String: ${stringBox.value}");

  var doubleBox = Box(3.14);
  print("Double Box: ${doubleBox.value}");
}

10.Pembatasan Tipe Dengan Class Abstract

  • Class AnimalCage<T extends Animal> merupakan generic class yang hanya dapat menerima tipe data yang merupakan turunan dari Animal.

Kode Program VS Code:


// Nama  : M.ALGERIJA HERTYAZ PASLAM
// NIM   : 251410021
// Kelas : SI2A
abstract class Animal {
  void makeSound();
}

class Dog implements Animal {
  @override
  void makeSound() {
    print("Woof!");
  }
}

class Cat implements Animal {
  @override
  void makeSound() {
    print("Meow!");
  }
}

class AnimalCage {
  T animal;

  AnimalCage(this.animal);

  void sound() {
    animal.makeSound();
  }
}

void main() {
  var dogCage = AnimalCage(Dog());
  dogCage.sound();

  var catCage = AnimalCage(Cat());
  catCage.sound();

  // var wrong = AnimalCage("test"); // ❌ Error
}

11.Praktik Generic Class & Fungsi

  • Pada program ini, Repository<T> merupakan generic class yang digunakan untuk mengelola dan menyimpan data dalam bentuk list dengan tipe yang fleksibel.

Kode Program VS Code:


// Nama  : M.ALGERIJA HERTYAZ PASLAM
// NIM   : 251410021
// Kelas : SI2A
// Repository Generic
class Repository {
  List _items = [];

  void save(T item) {
    _items.add(item);
  }

  T getById(int id) {
    return _items[id];
  }

  List getAll() {
    return _items;
  }
}

// Fungsi swap
void swap(List list, int i, int j) {
  var temp = list[i];
  list[i] = list[j];
  list[j] = temp;
}

// Class Triple
class Triple {
  A first;
  B second;
  C third;

  Triple(this.first, this.second, this.third);
}

void main() {
  var repo = Repository();
  repo.save(10);
  repo.save(20);

  print(repo.getAll());

  var list = [1, 2, 3];
  swap(list, 0, 2);
  print(list);

  var triple = Triple("Age", 21, 1.75);
  print("${triple.first}, ${triple.second}, ${triple.third}");
}

13.Latihan

  • Method push() digunakan untuk menambahkan data ke dalam stack, pop() untuk mengambil dan menghapus data terakhir, dan peek() untuk melihat data teratas tanpa menghapusnya.

Kode Program VS Code:


// Nama  : M.ALGERIJA HERTYAZ PASLAM
// NIM   : 251410021
// Kelas : SI2A


class Stack {
  final List _items = [];

  void push(T value) {
    _items.add(value);
  }

  T? pop() {
    if (_items.isEmpty) return null;
    return _items.removeLast();
  }

  T? peek() {
    if (_items.isEmpty) return null;
    return _items.last;
  }
}


List mergeLists(List a, List b) {
  return [...a, ...b];
}


class Response {
  T? data;
  String? error;

  Response({this.data, this.error});
}

// =======================
// MAIN
// =======================
void main() {
  // Stack
  var stack = Stack();
  stack.push(10);
  stack.push(20);
  print('Peek: ${stack.peek()}');
  print('Pop: ${stack.pop()}');

  // Merge Lists
  var result = mergeLists([1, 2], [3, 4]);
  print('Merge: $result');

  // Response
  var res = Response(data: "Berhasil");
  print('Response: ${res.data}');
}

15.KESIMPULAN

✦ KESIMPULAN

  • Kesimpulan ​Multiple inheritance adalah konsep dalam pemrograman di mana satu kelas dapat mewarisi atribut dan metode dari lebih dari satu kelas induk. Konsep ini memudahkan penggunaan kembali kode dan menggabungkan fungsi dari beberapa kelas, tetapi juga perlu digunakan dengan hati-hati agar tidak menimbulkan konflik atau kerumitan dalam program..!

✦ PENUTUP
