1.Tanpa Generic

  • ​Generic adalah istilah untuk sesuatu yang bersifat umum, tidak khusus, dan dapat digunakan dalam banyak situasi. Kata ini sering dipakai dalam berbagai bidang seperti bahasa, teknologi, obat-obatan, dan pemrograman. Sesuatu yang generic biasanya tidak memiliki ciri yang spesifik atau unik. Contohnya, kalimat “Semangat terus” disebut generic karena bisa ditujukan kepada siapa saja

class Box {
  dynamic data;

  Box(this.data);
}

void main() {
  // Menyimpan data awal
  var box = Box(42);

  // Menampilkan data awal
  int value = box.data;
  print("Nilai awal: $value");

  // Mengubah data
  box.data = "Hello";

  // Menampilkan data setelah diubah
  print("Data setelah diubah: ${box.data}");
}
