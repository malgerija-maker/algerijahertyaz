10.Pembatasan Tipe Dengan Class Abstract

  • Batasan <T extends Animal> memastikan bahwa hanya objek yang memiliki perilaku makeSound() yang dapat digunakan dalam class ini.

Kode Program VS Code:


// Nama  : MARTA SAPUTRA
// NIM   : 251410020
// Kelas : SI2A

abstract class Animal {
  void makeSound();
}

class Dog implements Animal {
  @override
  void makeSound() {
    print("Woof!");
  }
}

class Cat implements Animal {
  @override
  void makeSound() {
    print("Meow!");
  }
}

class AnimalCage {
  T animal;

  AnimalCage(this.animal);

  void sound() {
    animal.makeSound();
  }
}

void main() {
  var dogCage = AnimalCage(Dog());
  dogCage.sound();

  var catCage = AnimalCage(Cat());
  catCage.sound();

  // var wrong = AnimalCage("test"); // ❌ Error
}

11.Praktik Generic Class & Fungsi

  • Class Triple<A, B, C> merupakan generic class dengan tiga parameter tipe yang digunakan untuk menyimpan tiga jenis data yang berbeda dalam satu objek.

Kode Program VS Code:


// Nama  : MARTA SAPUTRA
// NIM   : 251410020
// Kelas : SI2A

// Repository Generic
class Repository {
  List _items = [];

  void save(T item) {
    _items.add(item);
  }

  T getById(int id) {
    return _items[id];
  }

  List getAll() {
    return _items;
  }
}

// Fungsi swap
void swap(List list, int i, int j) {
  var temp = list[i];
  list[i] = list[j];
  list[j] = temp;
}

// Class Triple
class Triple {
  A first;
  B second;
  C third;

  Triple(this.first, this.second, this.third);
}

void main() {
  var repo = Repository();
  repo.save(10);
  repo.save(20);

  print(repo.getAll());

  var list = [1, 2, 3];
  swap(list, 0, 2);
  print(list);

  var triple = Triple("Age", 21, 1.75);
  print("${triple.first}, ${triple.second}, ${triple.third}");
}

13.Latihan

  • Class Response<T> merupakan generic class yang digunakan untuk menampung hasil proses, baik berupa data maupun error.

Kode Program VS Code:


// Nama  : MARTA SAPUTRA
// NIM   : 251410020
// Kelas : SI.2A


class Stack {
  final List _items = [];

  void push(T value) {
    _items.add(value);
  }

  T? pop() {
    if (_items.isEmpty) return null;
    return _items.removeLast();
  }

  T? peek() {
    if (_items.isEmpty) return null;
    return _items.last;
  }
}


List mergeLists(List a, List b) {
  return [...a, ...b];
}


class Response {
  T? data;
  String? error;

  Response({this.data, this.error});
}

// =======================
// MAIN
// =======================
void main() {
  // Stack
  var stack = Stack();
  stack.push(10);
  stack.push(20);
  print('Peek: ${stack.peek()}');
  print('Pop: ${stack.pop()}');

  // Merge Lists
  var result = mergeLists([1, 2], [3, 4]);
  print('Merge: $result');

  // Response
  var res = Response(data: "Berhasil");
  print('Response: ${res.data}');
}

15.KESIMPULAN

✦ KESIMPULAN

  • Kesimpulan ​Multiple inheritance adalah konsep di mana sebuah kelas anak dapat mewarisi atribut dan metode dari dua atau lebih kelas induk sekaligus. Kelebihan utamanya adalah meningkatkan penggunaan ulang kode dan fleksibilitas karena kelas anak dapat menggabungkan fungsionalitas dari berbagai sumber. Namun, konsep ini memiliki kelemahan signifikan, yaitu: Diamond Problem – ambiguitas ketika dua kelas induk memiliki metode dengan nama yang sama. Kompleksitas tinggi – kode menjadi sulit dipelihara, dipahami, dan rawan kesalahan. Tidak semua bahasa mendukung – C++ mendukung, sementara Java dan C# tidak mendukung secara langsung (sebagai gantinya menggunakan interface).!

16.PENUTUP

✦ PENUTUP

  • Penutup ​Setelah memahami secara menyeluruh tentang multiple inheritance, dapat kita simpulkan bahwa konsep ini merupakan salah satu fitur paling kontroversial dalam pemrograman berorientasi objek (OOP). Multiple inheritance memungkinkan sebuah kelas anak mewarisi atribut dan metode dari dua atau lebih kelas induk sekaligus. Di satu sisi, fitur ini menawarkan fleksibilitas dan efisiensi yang tinggi dalam hal penggunaan ulang kode. Namun di sisi lain, fitur ini juga membawa tantangan kompleksitas yang tidak boleh diabaikan begitu saja.!
